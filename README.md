The funniest single-line safety warning label that should come printed on every human being — a deadpan printed-label warning whose punch lands in the last few words: the human goes quiet for the rest of the day because it just remembered something embarrassing it did in 2013.

## The entry

> WARNING: This human may suddenly go quiet for the rest of the day after remembering something embarrassing it did in 2013.

## Run it

```sh
node main.mjs
```

This writes the entry to `/output/entry.txt` and validates it against the bounty gate first: one single line, 100–160 characters, non-blank, starting with `WARNING:`. Run `npm test` to re-validate the entry and the written output file.
